# 融合序列语义特征的 ATM DNA 损伤响应激酶适配性机器学习解析

> 将蛋白语言模型嵌入与理化描述符结合，解析 ATM 激酶对候选分子的适配性，服务放疗增敏与基因组稳定研究。

## 一、方法

- **模型**：GINE 边属性图同构网络

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：545 条样本，2 类
- **标签协议**：abs_gap
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
